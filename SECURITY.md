# Security Policy

## Reporting a vulnerability

If you find a security problem in Petlibro Local, please report it privately rather than opening a public issue.

Use the **Report a vulnerability** button on the repository's [Security tab](https://github.com/smcneece/petlibro-local/security). That opens a private thread that only the maintainer can see.

Please include what you found, how to reproduce it, and which version you tested. I'll reply as soon as I can and credit you in the fix if you'd like.

## Supported versions

Only the latest release is supported. Security fixes are not backported.
